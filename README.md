# BanHang POS (Lite)

App ban hang tai quay don gian, lay cam hung tu Viethas POS. Chay nhu mot mobile web app (PWA) - mo bang trinh duyet tren dien thoai va co the "Them vao man hinh chinh" de dung nhu app that.

## Tinh nang (MVP)

- **Ban hang**: chon san pham tu luoi, xem gio hang, thanh toan.
- **San pham**: them / sua / xoa san pham, quan ly gia va ton kho.
- **Lich su hoa don**: xem danh sach hoa don da ban, chi tiet tung don, tong doanh thu trong ngay.

Du lieu duoc luu tren `localStorage` cua trinh duyet (khong can backend) - phu hop de demo va dung ca nhan. Ton kho tu dong tru khi thanh toan thanh cong.

## Chay thu

```bash
npm install
npm run dev
```

Mo dia chi hien thi trong terminal bang trinh duyet dien thoai (cung mang wifi) hoac trinh duyet may tinh o che do gia lap mobile.

## Build production

```bash
npm run build
npm run preview
```
